# Monumental

Site da Monumental, empresa de estruturas de palco e audiovisual para eventos em Brasília.

[![Ver site no ar](https://img.shields.io/badge/Ver%20site%20no%20ar-00F5FF?style=for-the-badge&labelColor=0D1117)](https://monumental-site.vercel.app) [![Portfólio](https://img.shields.io/badge/Portfólio-FF00E4?style=for-the-badge&labelColor=0D1117)](https://aknoleonel.github.io)

## Sobre o projeto

Site com posicionamento premium para uma empresa que monta palcos, painéis de LED e sistemas de som line array. A página mostra o acervo técnico e os números da empresa e leva o visitante a pedir orçamento.

## Destaques

- Hero com números de impacto: anos de mercado, eventos entregues e engenharia com ART
- Acervo técnico dividido por solução: LED, som line array e estruturas
- Botões de orçamento em cada serviço
- Integrações via @next/third-parties e animações com Framer Motion

## Tecnologias

Next.js · React · TypeScript · Framer Motion

## Rodando localmente

```bash
npm install
npm run dev
```

Para gerar a versão de produção: `npm run build`.
